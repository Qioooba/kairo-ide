# Kairo IDE 未来路线图

## 近期（Phase 1+ 收尾）

- Windows 10 真实环境验证
- JDK 6 + Tomcat 6 闸门探针执行
- 性能门禁全部通过
- UI 截图回归建立基线
- 真实遗留项目 E2E 验证

- 可访问性 WCAG AA 全面达标

## 远期（Phase 3+）

- 远程 Linux Agent 实际实现
- Maven 项目完整支持
- 多模块调试稳定版
- 企业合规性套件正式版
- 性能优化：大项目索引加速
