## What is *not* locked down (the honest list)

These are **known broken / known not-built at this tag**. The
user explicitly accepted the gap when scoping the v0.3 round.

1. **Tomcat 6 real smoke is not green.** `bundled/tomcat6/`
   has only `README.md`. `KAIRO_TOMCAT6_HOME` is unset on this
   machine. `scripts/verify-e2e.ps1` would fail at the
   preflight step. This is `BLOCKERS.md` B-002 and is the
   primary dependency for unlocking CI's
   `windows-smoke-real-tomcat` job.
2. **JDT LS is not wired in the UI.** The Go side has a JDT LS
   manager (`internal/jdtls`, ~2.5s of unit tests passing), but
   the Theia side (`packages/java-extension`) has no live
   LanguageClient. The `setState('ready')` early-return in the
   extension's "ready" hook is still there — to be removed
   when JDT LS actually initializes.
3. **Debug is not built.** No JDWP attach, no breakpoints UI,
   no debug adapter. Tracked for P7.
4. **`pnpm-lock.yaml` fails `prettier --check` unconditionally**
   (project-wide, pre-existing). The pre-commit hook is
   bypassed for the baseline commit; this needs a
   `.prettierignore` entry (or a hook fix) as a small follow-up.
5. **`verify-e2e.ps1` passes `--data-dir` flag to the agent**,
   but the agent only accepts `--config` / `--bind` / `--port` /
   `--log-level` / `--require-auth`. Data dir is honoured via
   `KAIRO_DATA_DIR` env var (which the script *also* sets, so it
   accidentally works). This is a pre-existing script bug —
   either remove the flag from the script or add the flag to
   `internal/config/config.go`. Tracked as follow-up.
6. **The Theia shell smoke only proves the page renders, not
   that the full chain works.** The existing Playwright
   (`tests/e2e/theia-smoke.cjs`) opens the page, asserts the
   status bar + Monaco mount, and snapshots 3 screens. It does
   not open a project, wait for JDT LS, exercise a build
   deploy, or hit Tomcat. Full chain E2E is P4.

## Follow-up work for v0.3 (Java Editing Preview)

Pulled directly from the user's round-2 brief, in execution
order. None of this work is in this commit; the baseline only
records the *starting state*.

1. **P1 (this file).** Done.
2. **P2 — Real Java editing.** Wire JDT LS end-to-end: launch
   from the Theia `java-extension`, register the language
   client, do not call `setState('ready')` until the LS
   actually answers. Then add: syntax diagnostics, completion
   (vars / fields / methods / classes), Ctrl-click + F12 go to
   definition, Shift+F12 references, outline, hover, quick
   fix for unresolved imports, source-root / output / WEB-INF
   classpath for non-Maven projects, JDT LS crash restart,
   status display. Verify against `legacy-sample` and a second
   realistic Java project.
3. **P3 — Real encoding support.** Status bar shows encoding;
   "Reopen with Encoding" is a real flow, not a toast. Save
   preserves the original encoding byte-for-byte. Cover
   GBK / UTF-8 / UTF-8-BOM / GB18030 / ISO-8859-1. Reject
   saving when the chosen encoding cannot represent the
   buffer. Find-and-replace preserves per-file encoding. Verify
   on Java / JSP / properties.
4. **P4 — Playwright full chain.** Real run of:
   open project → open Java file → wait for JDT LS ready →
   completion → go-to-def → build → deploy → start Tomcat →
   view logs → open app → modify JSP → save → re-sync → refresh
   browser → stop Tomcat. Capture the screenshots the user
   listed.
5. **P5 — Runtime Client unit tests.** Test the
   `@kairo/runtime-extension` client: dynamic `{id}` path
   expansion, multiple path params, query encoding (incl. CJK +
   spaces + special chars), GET / POST / PUT / DELETE,
   200 / 400 / 401 / 403 / 404 / 500, `ok:false` envelope,
   non-JSON, invalid JSON, network, timeout, AbortController,
   response envelope unwrap, requestId / correlationId
   propagation.
6. **P6 — Windows real-machine verification.** A dedicated
   Windows 10 / Win 11 low-spec VM, Chinese username, Chinese
   project path, path with spaces, JDK 6, Tomcat 6.0.30, GBK
   project, non-admin, no leftover `java.exe` after stop, JDWP
   port released. Cold-start, IDE idle RSS, JDT LS RSS, open
   project, first completion, single-file compile, full-text
   search — all measured and recorded.
7. **P7 — Debug.** First on modern JDK: JDWP Tomcat launch,
   JDWP attach via Theia Java Debug Adapter, Servlet breakpoint
   hit, threads / call stack / variables / watch / step over /
   step into / step out / continue / stop / debug console.
   Then Java 6 minimum-viable: attach, line breakpoint hit,
   local vars, continue / step over. HotSwap later.
