## 目标
统一 Kairo IDE 的设置、快捷键、通知、状态栏、问题面板、工具栏和编辑器体验，建立一致的 UX 规范。

## 用户价值
用户获得一致的 IDE 操作体验，包括统一的设置界面、快捷键管理、通知中心、问题面板和工具栏。

## 范围
- 设置偏好：Kairo 专属设置项定义与默认值
- 设置服务：设置读写、持久化和同步服务
- 快捷键管理：可视化快捷键配置面板
- 通知中心：统一的通知消息管理，支持分类、历史和操作
- 状态栏贡献：状态栏扩展，显示项目状态、JDK 版本、内存使用等
- 问题面板：编译错误、警告和 lint 结果的统一展示
- 工具栏：可自定义的工具栏组件
- 编辑器偏好：编辑器字体、缩进、换行等设置
- 编辑器贡献：编辑器右键菜单、装饰等扩展
- 诊断命令：IDE 诊断数据收集命令

## 非范围
- 主题引擎（使用 Theia 原生主题系统）
- 布局持久化
- 多窗口管理
- 国际化/多语言支持

## 实现摘要
所有功能在 `packages/theia-product` 中实现。设置服务提供统一的配置读写接口，快捷键面板使用 Theia keybinding 组件。通知中心基于 Theia 通知系统扩展，支持分类过滤和历史。状态栏扩展通过 Theia StatusBar 贡献点添加。问题面板基于 Theia Problems 视图定制。工具栏使用自定义工具栏组件，支持拖拽排序。编辑器扩展通过 Monaco 编辑器 API 实现。
