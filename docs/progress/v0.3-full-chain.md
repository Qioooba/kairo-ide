# Progress — v0.3-full-chain

> Tag: `v0.3-full-chain`
> Round: P4 (Playwright full chain)
> Date: 2026-07-18

## What is in this tag

Two new e2e tests ship with this round, both real:

- `tests/e2e/api-smoke.cjs` — CI-friendly. Hits the
  Runtime Agent directly over HTTP. No browser, no
  Playwright. Just `node` + a running agent. Covers the
  full wire surface: health, JDT LS GET / POST / DELETE,
  encoding detect (GBK + UTF-8-BOM + plain UTF-8), encoding
  recode (utf-8 -> gbk -> utf-8 round-trip preserves
  Chinese), workspace open, build (cleanly refuses without
  a JDK), deploy, server start (gated on B-002).

- `tests/e2e/full-chain.cjs` — Playwright-driven. Boots a
  headless Chromium, navigates to the Theia browser IDE,
  asserts all Kairo status bar entries are present, exercises
  the command palette for "Kairo: Reopen with Encoding",
  "Kairo: Build", "Kairo: Build & Deploy", and captures 8
  screenshots under `docs/screenshots/`. Gated steps (e.g.
  Tomcat 6 server start) log a `GATED` line and continue;
  they do not fail the test.

The existing `tests/e2e/theia-smoke.cjs` is untouched.
The new `test:api` and `test:full` scripts are added to
`tests/e2e/package.json`.

## What is NOT in this tag

- **Real JDT LS completion / diagnostics in the editor.**
  The P2 skeleton wires the HTTP state machine; the LSP
  frame bridge from agent to Monaco is the next round
  (`v0.3-jdt-ls-bridge`). Without it, the Playwright test
  cannot open a Java file and request completion.
- **Real Tomcat 6 start + live JSP edit + browser refresh.**
  The full Playwright happy path is gated on B-002
  (Tomcat 6.0.53 binary not vendored). Once that lands,
  the existing `full-chain.cjs` will already exercise
  start / log tail / open application / modify JSP /
  re-deploy / stop — only the gated step flips from
  `GATED` to `PASS`.
- **JDT LS auto-start on project open.** Currently the
  user must run "Kairo: Reopen with Encoding" and the
  JDT LS start command manually. A `frontendApplication.onStart`
  hook that fires `javaSvc.ensureStarted({ initializeRootURI })`
  when a workspace is opened is a small follow-up.
- **Editor-driven file open via Playwright.** The test
  asserts the status bar entries (which proves the editor
  is alive) but does not yet type into a file or invoke
  the Monaco completion provider. Both are doable but
  need the LSP frame bridge to actually surface
  completions.

## Reproduction

```powershell
# 1. Start the agent
& "F:\ideaSpace\kairo-ide\runtime-agent\bin\kairo-runtime.exe" `
  --bind 127.0.0.1 --port 18096 --log-level info

# 2. API smoke (no browser)
cd F:\ideaSpace\kairo-ide
node tests/e2e/api-smoke.cjs 18096 2>&1 | Tee-Object docs\progress\api-smoke-v0.3-full-chain.txt

# 3. Full-chain Playwright (needs the Theia browser running on :3000)
pnpm --filter @kairo/browser start &
# ... wait for the Theia shell
node tests/e2e/full-chain.cjs http://127.0.0.1:3000 18099 2>&1 | Tee-Object docs\progress\full-chain-v0.3-full-chain.txt
```
