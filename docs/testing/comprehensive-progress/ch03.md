## 缺陷/环境台账（本轮新增，详见 MASTER.md）

### ENV-20260829-901 (P0-环境) — Windows 下 agent dataDir 被 Go 解释为盘根相对路径
- 现象：lane.sh 生成的 agent.yaml 写 MSYS 路径 `/g/spaces/...`，Go agent（原生 PE）按"当前盘符根相对路径"解析为 `G:\g\spaces\...`，dataDir/bundledDir 全部落到**仓库外** `G:\g\`；agent-state.json、builds、deployments、auth 持久化在通道目录之外，`lane.sh reset` 清空的是空目录 → **状态重置失效、跨轮次污染**。
- 修复：`lane.sh write_config` 经 `cygpath -m` 转换为 `G:/spaces/...` 再写入 yaml；杂散 `G:\g` 已清理。修复后 reset 后状态文件正确落在 `.test-lanes/A/data/`（本表 013 的断言即证据）。

### ENV-20260829-902 (P1-环境) — lane.sh 进程管理在 Git Bash 下失效
- 现象：`stop` 后 node/kairo-runtime 原生进程存活（MSYS pid ≠ Windows pid，`kill` 无法触达；`lsof`/`pkill` 在 Windows 不存在）→ 端口占用导致后续 theia 起不来、构建时 conpty.node EBUSY。
- 修复：pid 文件经 netstat 反查写入真实 Windows pid（`resolve_winpid`）；停止用 `taskkill //F //T`（树杀）；lsof 缺失时用 netstat/awk 等价替换。

### TEST-20260829-903 (P2-基建) — smoke WELC 前提与 Windows 对话框选择器
- smoke 第3条在 agent 连接正常 + legacy-sample 存在时不再自动弹 Welcome（`.kairo/project.yaml` 自动绑定 = 正确产品行为），改为像 ch08 一样打开纯净空工作区（`openIdeAt` + mkdtemp）。
- ch05 TC-MENU-002/003：该 Open 对话框树所有行的 `title` 属性镜像对话框当前解析路径（Windows 构建实测共享同值），行定位改为 `.theia-TreeNodeSegmentGrow` 标签文本匹配；展开用"单击选中 + ArrowRight"（鼠标点 expansion toggle 在 headless 下不稳定）。
- 良性噪音 allowlist：对话框关闭取消在途目录监听产生 `filesystem:FileService ERROR Canceled`。
