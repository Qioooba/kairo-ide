## 本章修复的测试/产品问题

### TEST-20260830-904 — `openIde` 在 shell 挂载前抢点 Trust 导致整章落入 Restricted Mode
- 现象：首次运行 TC-WIN-004 时 F1 命令面板超时；单独重跑仍复现。
- 根因：helper 在 `#theia-app-shell` 出现前点击信任按钮，超时被吞掉；后续页面处于 Restricted Mode，键盘/命令贡献未启用。
- 修复：`openIde` 先等待 shell，再以 20s 超时点击信任；点击后再次等待 shell，并在仍显示 Restricted Mode 时于启动边界直接失败。
- 回归：TC-WIN-004 单测通过，整章 9/9 通过。

### TEST-20260830-905 — 持久化布局使底部面板/状态栏测试依赖初始状态
- 现象：命令本身正常切换，但测试默认假设面板和状态栏启动时可见；不同浏览器 profile/历史布局下首个 toggle 方向相反，产生假失败。
- 修复：新增可见性读取（ComputedStyle、`lm-mod-hidden`、矩形高度）与 `setBottomPanelVisible`/`setStatusBarVisible` 状态归一化，再验证隐藏/恢复。
- 回归：TC-WIN-008 通过；整章 Windows Chromium 9/9 通过。
