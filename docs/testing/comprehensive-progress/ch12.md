## 本章修复的缺陷

### BUG-20260826-307 — 折叠与 XML 块注释快捷键全部失效（P1）
- **关联用例**: TC-ED-007(xml)、TC-ED-009
- **位置**: `packages/theia-product/src/main/browser/kairo-idea-mac-keymap.ts:33-79`、`kairo-idea-windows-keymap.ts`
- **根因**: Theia 层绑定的 `editor.action.blockComment` / `editor.fold*` 在 Theia CommandRegistry 中不存在（@theia/monaco 只桥接 selectAll/clipboard/find 等），KeybindingRegistry 匹配后执行是静默 no-op。
- **修法**: 按 BUG-306 同类模式在 `kairo-idea-mac-monaco-keymap.ts` / `kairo-idea-monaco-keymap.ts` 以 `control.addCommand` 注册 Monaco 级 ⌘-/⌘=/⌘⇧-/⌘⇧= 与 ⌥⌘/（Win: Ctrl±/=、Ctrl+Shift+/）。
- **回归**: ED-007/ED-009 通过。

### BUG-20260826-308 — Output 面板抢占 ⌘⇧U，IDEA Toggle Case 失效（P1）
- **关联用例**: TC-ED-006
- **位置**: Theia `OutputFrontendContribution`（toggleKeybinding:"CtrlCmd+Shift+U"）→ 注册表先于 Monaco 吞掉 chord 并把焦点切到 Output 面板
- **根因/修法**: `reclaimToggleCaseChord()`（mac/windows 两个 monaco-keymap contribution 的 onStart）：unregister 该 chord 的三种写法变体，注册 `kairo.editor.toggleCase` 命令 + `ctrlcmd+shift+u` 键位（editorTextFocus）。Windows 侧同构实现。
- **回归**: ED-006 通过（探针证实按下后面板不再跳焦、单次执行转换成功）。

### BUG-20260826-309 — Find Action 浮层不聚焦查询框（P2）
- **关联用例**: TC-CMD-002（记录于 ch37）
- **位置**: `packages/search-extension/src/browser/find-action-widget.tsx`
- **根因**: body overlay 挂载晚于 shell 焦点恢复，React autoFocus 失效；Escape 因此也落在树组件上无法关闭浮层。
- **修法**: useEffect 显式 focus 输入框。
- **回归**: CMD-002 通过。

### BUG-20260826-310 — 键盘守卫过度拦截导致受保护编辑 chord 双发/丢发（P1）
- **关联用例**: TC-ED-005(删行×2)、TC-ED-007(⌘/ 注释+反注释抵消)、TC-ED-004(复制行×2 历史)等间歇性失败
- **位置**: `kairo-browser-keyboard-guard.ts`、`kairo-idea-mac-keymap.ts`、`kairo-idea-windows-keymap.ts`、`kairo-idea-mac-monaco-keymap.ts`
- **根因**: 守卫把 ~80 个非 Chrome 保留的 IDEA 编辑 chord 也 preventDefault+克隆。克隆经 KeybindingRegistry 匹配到 keymap 里登记的纯 Monaco action id，经 `MonacoCommandService` 的 NO_ACTIVE_HANDLER→delegate 桥**再执行一次**，与原生送达的那一份叠加 → 删行删两行、复制行翻倍、注释互相抵消；delegate 未就绪时则一次都不执行。
- **修法**:
  1. 守卫在 `.monaco-editor` 目标内只拦截 Chrome 保留 chord（NAV_RESERVED ∪ cmd/cmdr g/d/s/f/o/l/[ ]/1-9/f11），其余原生直达；
  2. 两个平台 keymap 删除全部纯 Monaco action id 条目（附 NOTE 注释）；
  3. 删行/移行改注册表级命令（kairo.editor.deleteLine / moveLineUp / moveLineDown），nullify Monaco 内建 Cmd+Backspace(delete-to-line-start)、Shift+Alt+↑↓(Copy Line) 遮蔽；
  4. Windows monaco-keymap 将 Ctrl+Y/Ctrl+D/Ctrl+Shift+M/Ctrl+Alt+Shift+J/Ctrl+Shift+/ 统一交给注册表命令；重复行使用模型编辑操作，避免 Monaco 内建命令竞争。
- **回归**: ch12 全量 17/17 通过；ch11 7/7、ch37 5/5 无回归。
