## 缺陷台账

### BUG-20260828-601 (P2) — 同 ch16 BUG-600（占位 range）

**现象/根因/修法**: 见 ch16 BUG-600；`xml-dtd-completion.ts:25` 的 `item()` 占位 `range: {1,1,1,1}` 导致 `web.xml` 的 28 项与 `TLD` 的 14 项建议被 Monaco 过滤，`probe-xml-suggest` 的 `count` 曾为 0 且 `message` 为 `No suggestions.`。

**验证**: 见 ch16。

### BUG-20260828-603 (P1) — XML 属性补全永不可达

**现象**: TC-XML-004 期望 `<web-app ` 后出现 6 项属性（`xmlns` 等），但实际返回元素列表（`context-param` 等 12 项）。

**根因**: `xml-dtd-completion.ts:134-155` 的 `if (isInsideOpenTag)` 元素分支与后置 `lastTagStart` 属性分支条件重叠（`lastOpen > lastClose`），元素分支恒先命中，属性分支永不可达。

**修法**: 见 ch16 BUG-601 节：`if (isInsideOpenTag) { const afterLt = lineBeforeCursor.substring(lastOpen+1); if (/\s/.test(afterLt)) return attributes; ... return elements; }`，移除重复分支。

**验证**: 重建后 `<web-app ` 的补全正确返回 6 项 `xmlns/...`，TC-XML-004 通过。

### 关联修复

- `webxml-completion.ts` 的 `ci`/`buildUrlPatterns` 同为占位 `range`，一并改为 `word` range 注入（见 ch16 BUG-600），虽不直接影响本章的 28/14 项，但修复了 `web.xml` 内 `servlet-class` 等位置的类名/URL 补全。
- 测试数据：`__kairo_large.xml` 从 980KB 扩大至 1.68MB，使 `>1MB` 阈值（`xml-dtd-validator.ts:25`）可被触发。
