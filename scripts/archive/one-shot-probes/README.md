# One-shot probes (archived)

These scripts are **one-shot diagnostic and QA probes** — ad-hoc E2E drivers, ASAR patch helpers, registry probes, and similar tooling used during development.

They are **not part of CI** and are not required to build or test Kairo IDE. Prefer the package-level `test` scripts and documented QA flows in `docs/` for repeatable verification.
